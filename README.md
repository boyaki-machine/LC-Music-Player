# LC Music Player（LCMP）

LC Music Player（LCMP）は、静かで個人的な音楽鑑賞体験を目指すネイティブ音楽プレイヤーです。楽曲情報を控えめに表示し、グラフィックイコライザーなどの可視化によって再生を楽しめるようにします。

macOS上のネイティブアプリとし、iPhone版にも共用できるよう、再生やプレイリストの機能と、画面表示、音声出力、ファイルアクセスなどのOS依存機能を分離する設計です。

## 仕様と設計

製品で目指す仕様は[基本設計書](docs/basic-design.md)に、単曲再生の構造と動作は[基本再生の実装設計](docs/playback-implementation.md)に記載しています。単曲再生にはSwiftUIとSFBAudioEngineを使用し、ローカルファイルの選択・再生・一時停止・停止・アプリ内音量を提供します。

製品の設計方針：

- ローカルの音楽ファイル／フォルダを選択して再生します。音楽ファイル自体はアプリへコピーしません。
- グラフィックイコライザーによる可視化を提供し、別の表示デザインも追加・切替できる構造にします。
- 可視化のための解析と、音声に効果を加える処理を分離します。
- 出力デバイスごとにアプリ内の再生音量を記憶し、再接続時に復元します。初めて使うデバイスでは現在のアプリ内音量を使用します。

単曲再生の対応形式はMP3、M4A（AAC・ALAC）、WAV、AIFF、FLACです。

## ローカルで起動する

macOS 14以降、Swift 6対応のXcode／Command Line Tools、Python 3を使用します。

```sh
python3 scripts/build-app.py
open build/LCMP.app
```

「ファイルを選択…」（Command＋O）で音源を選び、「再生」を押してください。Spaceで一時停止・再開できます。停止後は先頭から再生します。音源自体はコピーせず、選択はアプリを終了するまで保持します。

ビルドスクリプトは、公開依存を取得するときのキーチェーン・netrc検索を無効にします。Git設定やキーチェーンは変更しません。起動用アプリには動的frameworkと[依存ライセンス表示](docs/third-party-dependencies.md)を同梱します。

## テスト

```sh
./scripts/swift.sh test
LCMP_TEST_AUDIO_OUTPUT=1 ./scripts/swift.sh test
```

2つ目は既定出力先へ小さいテスト音を送る実再生テストです。通常のテストは音声を出力しません。ファイル選択画面、聴感、デバイス切替の手動確認方法は[実装設計](docs/playback-implementation.md)を参照してください。

開発途中の情報は次のローカル専用ファイルに記録します。どちらもGit管理対象外で、存在する環境でのみ参照します。

## Gitの運用

このリポジトリではGitflowを基にブランチを運用します。現在、リモートリポジトリは設定していません。

- `main`：リリース可能な履歴とバージョンタグを管理します。
- `develop`：日常の開発内容を統合するブランチです。
- `feature/<短い名前>`：`develop`から作成し、機能の作業完了後に`develop`へ統合します。
- `release/<バージョン>`：リリース準備時に`develop`から作成します。検証後に`main`へ統合してタグを付け、リリースブランチの変更を`develop`にも反映します。
- `hotfix/<短い名前>`：リリース済みバージョンへの緊急修正用として`main`から作成し、修正を`main`と`develop`の両方へ統合します。
- 通常の開発では`main`へ直接コミットしません。

初期状態のバージョンは`v0.0.1`です。公開やリモートでの共同作業を始める際に、プロジェクトの管理者がリモートURLを設定してください。

## ディレクトリとファイル

- `docs/`：製品および技術の設計書。
- `Sources/`：macOS画面と、再生制御・音源アクセス・再生アダプター。
- `Tests/`：状態遷移・デコード・音声出力の検証と独自のテスト音源。
- `scripts/`：公開依存の認証検索を抑止するSwift実行、アプリ作成、テスト音源生成。
- `LEARNINGS_CODEX.md`：ローカル環境のみで使用するセッションの知見・引き継ぎ記録。Git管理対象外です。
- `DEVELOPMENT_NOTES.md`：ローカル環境のみで使用する開発経緯・進捗・未決事項・チケット引き継ぎ。Git管理対象外です。
- `AGENTS.md`：コーディングエージェント向けのリポジトリ固有の作業指示。

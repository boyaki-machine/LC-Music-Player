# LCMP UI・UX設計

[設計書一覧](./README.md)に戻る。

本書はLCMPで目指す画面構成と操作を記述します。単曲再生の実装構造は[基本再生の実装設計](./playback-implementation.md)で管理します。

macOS版の外観と配置は、[チャコール・グラスと三角LEDの画面見本](../prototypes/led-player.html)を基準にします。画面見本の可視化は表示例であり、再生音に応じた描画は可視化機能が担当します。

## 1. 画面の方針

可視化と日常の再生操作をまとめたコンパクトなメイン画面を使用します。通常はメイン画面のみを表示し、音源管理や設定が必要なときに拡張画面を開きます。

- メイン画面にタイトルバーを表示しない。
- macOSのメインウィンドウと拡張ウィンドウは、適度に丸めた角丸を使用し、macOSの他のGUIより少しシャープな印象にする。
- 可視化を主役とし、楽曲名やアートワークを常設しない。楽曲情報は拡張画面で確認する。
- メイン画面の操作順序と構成はmacOSとiPhoneで共用できるようにする。
- メイン画面はiPhoneの画面幅に収まるサイズ感とし、ボタンの操作領域を確保する。
- ウィンドウの移動や画面の提示方法は、各OSの画面管理に合わせる。

## 2. メイン画面

### アニメーション領域

メイン画面の上部を、選択中の可視化デザインの置き場所とします。可視化デザインを切り替えても、操作領域の配置や再生状態を変えません。

macOSでは、この領域のドラッグでメインウィンドウを移動します。同じ領域のクリックまたはタップでシークバーを表示します。ドラッグとして扱った操作では、シークバーの表示状態を切り替えません。シークバーやその上の操作部をドラッグした場合も、ウィンドウを移動しません。


### 操作領域

アニメーション領域の下に、次の操作を配置します。

| 左からの順序 | 操作 | 動作 |
| --- | --- | --- |
| 1 | 前の曲 | 再生対象を前の曲へ変更する |
| 2 | 再生・一時停止 | 再生状態に応じて再生、一時停止、再開する |
| 3 | 次の曲 | 再生対象を次の曲へ変更する |
| 4 | 停止 | 再生を停止する |
| 5 | 音量 | アプリ内音量の縦型バーを開く |
| 6 | メニュー | 拡張画面を開閉する |

再生・一時停止ボタンを主操作として識別できる外観にします。アイコンにはアクセシビリティ上の名前を付け、再生状態に合わせて名前を更新します。利用できない操作は無効状態を明示します。

macOSの操作領域はチャコールを基調とし、背景が透けるグラスのような質感を使用します。主操作を大きな背景色の差で強調せず、記号の発光で状態を表します。透過・ぼかしを用いても操作の視認性を保ちます。

再生・一時停止ボタンは三角記号を常設し、再生中は緑のLED風に点灯、一時停止中は琥珀色、停止中は消灯に近い表示とします。小さなPLAY／PAUSE／STOPの表示を併用し、操作のアクセシビリティ名は一時停止・再開・再生に合わせます。

他の主操作ボタンも押したときに記号がLED風に光り、操作への反応を示します。一度の操作への短い発光と、再生中・画面を開いている間の状態表示を区別します。無効な操作は発光させません。マウス・タッチに加え、キーボード操作でも同じ反応を提供します。

| 操作 | LED風の反応・状態表示 |
| --- | --- |
| 前の曲・次の曲 | 押したときに短く緑に発光する |
| 停止 | 押したときに短く琥珀色に発光する |
| 音量・メニュー | 押したときに光り、開いている間は緑の点灯を保つ |
| ミュート | 押したときに光り、ミュート中は緑の点灯を保つ |

短い発光は操作後に消灯し、ボタンの外で操作を取り消しても残り続けません。状態を示す点灯は、その状態が終わると解除します。常時の点滅や明滅は使用しません。

### シークバー

通常はシークバーを表示せず、アニメーション領域をクリックまたはタップすると表示します。再生位置と時間を確認し、バーの操作で再生位置を変更できるようにします。表示時もメイン画面の操作ボタンを使えます。

macOSでは細いバーをアニメーション領域の下端へ重ねます。背景は透明または半透明とし、可視化を不透明な帯で隠しません。バーの見た目の高さと、操作を受け付ける範囲を区別します。

### 音量

音量ボタンを押すと、縦方向に調整できるバーを表示します。現在値を確認でき、上方向を大きな音量、下方向を小さな音量として扱います。

macOSの音量ポップアップは、現在値等を含めた全体をメインウィンドウの高さに収めます。ポップアップ外の領域をクリックすると閉じ、クリック先の通常操作も実行します。音量ボタンの再クリックでも閉じます。アプリから他のアプリへ移ったときも閉じます。

ポップアップ内にミュート操作を置き、解除時にはミュート前のアプリ内音量へ戻します。

変更するのはアプリ内の再生音量です。OSのシステム音量を直接変更しません。出力デバイスごとの音量記憶・復元は[基本設計](./basic-design.md)の出力制御に従います。

## 3. 拡張画面

メニューボタンでメイン画面の下に拡張画面を表示します。拡張画面を閉じても再生を継続し、選択中の音源・プレイリスト・可視化を維持します。

macOSではメインウィンドウに付随する拡張ウィンドウとして扱い、メインウィンドウとの位置関係を保ちます。2つのウィンドウは、ごく小さい間隔または隙間なしで配置します。

メニューボタンから拡張画面を開くときの初期表示は、現在の再生リストとします。

| 機能 | 扱う内容 |
| --- | --- |
| 音楽ファイル選択 | ローカル音源の選択と、現在の音源の確認 |
| プレイリスト編集 | プレイリストと収録曲の管理、再生順序の編集 |
| アニメーション切替 | 可視化デザインの選択 |
| その他設定 | 再生・表示等の設定 |

拡張画面は可視化領域から独立した操作領域です。ファイル選択取消や選択失敗によって、既存の音源を意図せず差し替えません。

## 4. 状態の伝え方

- 再生中・一時停止・停止は主操作のアイコンと操作可能なボタンで識別する。
- 音源が未選択の場合は、メニューから音源を選ぶ導線を示す。
- エラーは原因と回復操作をメイン画面でも識別できるようにする。楽曲名を大きく表示する方法で伝えない。
- 可視化表示の停止と再生制御を分離し、画面の開閉や可視化の切替で音源や音量を変更しない。
- ポインター操作に加え、キーボードと支援技術から表示切替・シーク・音量・メニューを操作できるようにする。

## 5. 可視化デザインの構成

アニメーション領域は可視化デザインを差し替えるためのコンテナとします。再生制御、解析データ、描画を別の責務として扱います。

可視化の実装は専用のフォルダにまとめ、各デザインをその配下のサブフォルダへ分けます。共通の解析データを各デザインへ渡し、デザインの変更がファイルアクセス、音源デコード、音量制御へ影響しない構造にします。

# Last Century ラジカセの実装設計

[設計書一覧](../README.md)に戻る。

## 1. 概要

「Last Century ラジカセ」は、1980〜1990年代のラジカセ・ミニコンポの表示部を模した可視化デザインである。アニメーション領域の左にカセットテープ、中央にアプリの動作状態を示す6つのインディケータ、右に左右の音量を示すレベルメーターを置く。外観はモノクロの液晶（灰緑の地に暗いインク）とし、落ち着いた印象にする。

- 操作部・再生・音量は他のデザインと共通で、切り替えても変わらない（[開発ガイド](10_player-ui-developer-guide.md)の「1つのPlayer UIに可視化デザインを追加する場合」）。
- 表示タブのカードは、タイトル「Last Century ラジカセ」、説明文「カセットテープで聞いた、あの頃のワクワクを再び。」とする。

## 2. 要件

### テープ

- テープが再生ヘッドの前（下部）を左から右へ流れるのを正転、その逆を逆転とする。正転では両方のリールが反時計回り、逆転では時計回りに回る。
- テープの位置（左のリールから右のリールへ巻き取った割合、0〜1）を持つ。端から端まで10分で巻き取る。左右のリールの巻き量は、テープの面積が移るものとして半径を決める。
- テープの送りの速さは一定で、各リールの回転の速さは自分の巻き量の半径に反比例する。巻き量が最小のとき45.5rpm、最大のとき18.9rpmとする。
- 下部のテープの点線は、テープが流れる向きに動く。流れの速さはリールの外周の速さの0.5倍とする。
- テープの位置はアプリの起動時に35%から始め、アプリを終了するまで保つ。
  - 再生中に端まで来たら、方向を反転して再生を続ける。
  - 次の曲が選ばれるたびに、位置を保ったまま方向を反転する。最後まで再生した曲をもう一度始めたときも反転する。
  - 同じ曲を設定の変更（音量の平均化の入切・目標の変更等）のために始め直したとき、再開・シークでは反転しない。
- テープは再生中だけ動く。一時停止・停止ではその場に止まる。

### インディケータ

上から次の順に並べる。点灯は暗いインクの枠と文字、消灯（機能が切）は淡い枠と文字とする。

| 項目 | 表示 |
| --- | --- |
| 電源 | `BATTERY`（バッテリー動作、目立たせるため白黒を反転）／`AC POWER`／`POWER`（不明、消灯） |
| 出力 | `SPEAKER`（内蔵スピーカー）／出力機器の名前（Bluetoothのヘッドフォン等）／`HEADPHONES`（名前のない機器）／`NO OUTPUT`（消灯） |
| 形式 | 非可逆圧縮は形式とビットレート（`AAC 256kbps`、`MP3 320kbps`）、可逆・非圧縮は形式と音源ファイルのサンプルレート（`FLAC 96kHz`、`WAV 44.1kHz`。出力のレートではない）。曲がなければ`NO TAPE`（消灯） |
| 音量の平均化 | `ALC mode 16`／`18`／`23`（目標の音量、LUFSの絶対値）／`ALC OFF`（消灯） |
| 重低音の強調 | `B-BOOST mode 1`（弱）／`mode 2`（強）／`B-BOOST OFF`（消灯） |
| テープの方向 | `FORWARD ▶`／`◀ REVERSE` |

- 枠に入らない文字は横に縮め（最大0.72倍）、それでも入らなければ末尾を「…」で省く。
- ALC（Automatic Level Control）は、当時の機器に共通の一般的な技術用語として使う。

### レベルメーター

- 左右の各列は24段で、下から12段・6段・6段の3つの区分を持つ（液晶なので色は1色）。
- 各チャンネルのRMSに3dBを足した値の−30〜0dBを、0〜24段に写す。
- 音が大きくなると即座に点灯し、小さくなると約300msで全段から消える。動きを減らす設定では、落ち方を省いて現在の値をそのまま表示する。
- 一時停止では表示を保ち、停止・自然終了では消灯する。データの欠落（250ms）では消灯する。画面に文字は出さず、支援技術へは「解析データ待ち」を伝える。

### 寸法

360×144ptの表示領域で次の位置に描く。

| 部分 | 位置・寸法 |
| --- | --- |
| カセット | 外枠 x12〜202・y12〜132、リールの中心 (69, 58)・(145, 58)、ハブの半径10.5pt（歯6本）、巻き量の半径12.05〜29pt、ガイドの中心 (32, 116)・(182, 116)・半径6pt |
| テープの点線 | 線5pt・すき間2.5pt |
| インディケータ | x220、幅64pt・高さ13pt、間隔6.2pt、上端17pt、文字7pt（セミボールド）、角丸2.5pt |
| レベルメーター | 列の左端 x304・329、幅15pt、y14〜118、ラベル（L・R）9pt |

- 線は、外枠などの背景を0.75pt・淡い色、リール・テープ・点灯した枠を1.1pt・暗いインクとする。
- 表示領域が360×144ptと違う比率のとき（iPhoneの横置き等）は、高さに合わせて拡大し、余った幅をカセットの左・3つのまとまりの間・メーターの右の4か所に等しく配る。

## 3. 方式

| 担当 | 内容 |
| --- | --- |
| `RadioCassetteTape` | テープの位置・方向・リールの角度・点線の位置。経過時間で進め、次の曲で反転する値型 |
| `RadioCassetteStatus`・`RadioCassetteFormat` | インディケータの元の値と、表示する文字への変換。形式は再生中の曲から読む |
| `RadioCassetteMeter` | RMSから段数への変換と落ち方 |
| `RadioCassetteDriver` | 再生状態・表示の可否・解析結果・インディケータの値を受け、30fpsの時計で1コマ（`RadioCassetteFrame`）を作って描画部へ渡す |
| `RadioCassetteMonitor` | 表示中だけ、電源（macOSはIOPowerSources、iPhoneは電池の状態）と出力機器を監視する |
| `RadioCassetteLayers` | Core Animationのレイヤーで描く |
| `RadioCassetteView` | SwiftUIの入口。インディケータの元の値を観測してdriverへ渡し、レイヤーを持つView（`NSView`／`UIView`）を置く |
| `RadioCassetteThumbnail` | 表示タブのカードの絵 |

- 解析は他のデザインと同じ設定（16帯域・30Hz）を共有し、左右のRMSだけを使う。
- 曲が替わったことは`LibraryController.trackChangeID`で知る。曲を選ぶ操作（次の曲・前の曲・リストからの選択・自然な曲送り）で、別の曲か、最後まで再生した同じ曲を始めたときだけ変わる。設定の変更のための始め直し・再開・シークでは変わらない。driverは最初に見た値では反転せず、それ以後の変化ごとに反転する。曲を選んでいない間（再生側の曲がないとき）は値を渡さない。表示していない間に複数回替わっても、次に表示したとき1回だけ反転する。
- 出力機器の名前は`OutputDevice.name`（macOSはCore Audioの機器名、iPhoneは経路のポート名）、内蔵スピーカーかどうかは`OutputDevice.isBuiltInSpeaker`（macOSは内蔵機器のデータソースが内部スピーカー、iPhoneはポートの種類）で知る。どちらも表示用で、機器の同一性（音量の記憶の鍵）には含めない。macOSでは、同じ内蔵機器でヘッドフォンを抜き差ししたことを知るため、データソースの変更も監視する。
- 電池の監視（iPhone）は、常時表示と同じアプリ全体の設定を使う。`BatteryMonitoring`が要求の数を数え、誰かが必要としている間は有効にしておく。
- 形式は、曲ごとに1回だけ読む。ファイルはプレイヤーと同じCore Audio（`AudioFile`）で開き、形式ID・サンプルレートと、音声データの量と長さから求めた平均ビットレート（タグやアートワークを含まない）を得る。iPhoneの「ミュージック」の曲は`AVURLAsset`のトラックの形式と推定ビットレートから求める。
- App Sandboxでは、プレイヤーが再生している間だけファイルへのアクセスを持つ。読めなかったときは拡張子で形式名だけを示し、再生が始まったときに読み直す。

## 4. 実装

### 省電力の描画

- 形はCore Animationのレイヤーとして一度だけ作り、合成はレンダーサーバー（GPU）が行う。1コマで変えるのは、2つのハブの回転、点線の位相（`lineDashPhase`）、前のコマの段数と今の段数のあいだにあるメーターのセルの色、変わったインディケータだけである。SwiftUIのViewは毎コマ更新しない（driverは描画部を直接呼ぶ）。
- インディケータの表示（文字と点灯）は、元の値かテープの方向が変わったときだけ作り直す。レイアウトは、大きさか表示の倍率が変わったときだけやり直す。
- 巻き量の円とテープの経路は、半径が0.02pt以上変わったときだけ作り直す（10分で端から端までなので、数秒に一度）。
- 変更はアニメーションなしのトランザクションで反映する（暗黙のアニメーションを作らない）。
- 時計は表示中かつ再生中だけ動かす。一時停止・停止・非表示では止め、インディケータの値が変わったときだけ1コマ描く。
- 文字は表示の倍率×拡大率で描き、拡大してもにじまないようにする。インディケータの文字を替えるときは、その場で描き直す（寸法はすぐ変わるので、古い文字が新しい寸法で1コマ表示されるのを防ぐ）。
- macOSでは、上下を反転した（`isFlipped`）レイヤー付きのViewに図形のレイヤーを入れる。AppKitがそのViewのレイヤーを上から下の座標に保つので、周りのView（SwiftUIのホスト等）の向きによらず、iPhoneと同じ座標で描ける。図形のレイヤー自身は反転しない。

### 時刻

- 解析結果は推定の提示時刻まで待ってから採用する（他のデザインと同じ。採用は25ms早める）。
- テープは時計の経過時間（最大0.1秒）で進める。

## 5. 検証

```sh
LCMP_TEST_AUDIO_OUTPUT=0 LCMP_UI_SNAPSHOTS=build/player-ui-qa \
./scripts/swift.sh test --disable-automatic-resolution --filter RadioCassette
```

| 対象 | 合格基準 |
| --- | --- |
| テープ | 巻き量の最小・最大で45.5・18.9rpm、正転で反時計回り、35%から390秒で端に着いて反転、次の曲で位置を保って反転 |
| インディケータ | 各状態の文字と点灯・反転、形式の文字（ビットレートとサンプルレートの使い分け）、実際のWAV・AACファイルの読み取り（AACは平均ビットレート）、長い名前の縮小と省略、文字の変更時の即時の描き直し |
| メーター | RMSから段数への変換、約300msでの落ち方、動きを減らす設定 |
| driver | 表示中かつ再生中だけ時計が動く、一時停止で保持、停止で消灯、最初の選択では反転せず次の選択で反転、非表示では描かない |
| 曲の変化 | `trackChangeID`が別の曲・最後まで再生した曲の再開始で変わり、同じ曲の選び直し・再生と一時停止・設定の変更による始め直しでは変わらない（後者は実出力のテスト） |
| 描画 | メーターのセルが段数の上下に追従すること（差分だけを塗り替えても全体が正しい）。レイヤーを画像にして、バッテリーの反転・点灯と消灯の枠・メーターの段・巻き量の位置・ハブの回転・横長の画面での配置を画素で確かめる。macOSのViewが反転したレイヤー付きのViewであること。`LCMP_UI_SNAPSHOTS`を指定すると画像を保存する |

- 画面上の見え方（アプリの中での拡大、iPhoneの横置き、出力の切り替え・電源の抜き差しへの追従）は、確認用のアプリで手で確かめる。

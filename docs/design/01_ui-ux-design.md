# LCMP UI・UX設計

[設計書一覧](../README.md)に戻る。

本書は、LCMPで目指す画面構成と操作を記述する。macOS版の外観は、チャコール・グラスの操作部と、LED風に光る三角の再生ボタンを基調とする。再生音に応じた描画は可視化機能が担当する。

実装は[コンパクト画面の実装設計](09_compact-ui-implementation.md)に記載する。

## 1. 画面の方針

可視化と日常の再生操作をまとめたコンパクトなメイン画面を使用する。通常はメイン画面だけを表示し、音源管理や設定が必要なときに拡張画面を開く。

- メイン画面にタイトルバーを表示しない。
- macOSのメインウィンドウと拡張ウィンドウは、適度に丸めた角丸を使用し、macOSの他のGUIより少しシャープな印象にする。
- 可視化を主役とし、楽曲名やアートワークを常設しない。楽曲情報は拡張画面で確認する。
- メイン画面の操作順序と構成はmacOSとiPhoneで共用できるようにする。
- メイン画面はiPhoneの画面幅に収まるサイズ感とし、ボタンの操作領域を確保する。
- ウィンドウの移動や画面の提示方法は、各OSの画面管理に合わせる。
- 常時点滅・明滅する装飾は使用しない。

### アプリのアイコン

アプリのアイコンは、画面と同じチャコール・グラスの地に、LED風に光る再生の三角とレベルメーターを置く。

- 上半分に、緑に光る再生の三角を置く。
- 下半分に、5列6段のレベルメーターを置く。点灯したセルは下の4段を緑、5段目を黄、6段目を赤とし、消灯したセルも暗い同系色で見せる。色は[可視化の外観](#5-可視化デザインの構成)の蛍光管LEDと共通にする。
- 楽曲名・アートワーク・文字は入れない。
- 色だけで意味を伝えず、メーターの段の高さでも読めるようにする。
- 16pxから1024pxまでの各サイズは、縮小ではなく図形から描き、32pxでもメーターの段が見えるようにする。作り方は[ビルド・配置とローカル配布](../build-and-deploy.md#アイコン)に記載する。

### インストーラー

macOS版はDMGで配布する。DMGを開くと、アプリをApplicationsフォルダへドラッグして入れるウィンドウを表示する。

- ウィンドウの内容領域は640×400pt。ツールバー・ステータスバー・パスバーは表示しない。
- アプリ（左、中心170, 176）とApplicationsフォルダ（右、中心470, 176）を128ptのアイコンで並べる。アプリの拡張子は表示しない。
- 背景はアプリのアイコンと同じチャコール・グラスの地とし、2つのアイコンのあいだに、Applicationsへ向かうLED風のシェブロン7つを置く。色は手前から緑5つ・黄・赤で、先へ行くほど明るくする。左上に「LC Music Player」、右上にアイコンと同じ配色の小さなレベルメーターを置く。
- アイコンの名前はFinderが描き、ライトモードでは黒、ダークモードでは白になる。名前の下に中間の灰色（#767c78）の板を敷き、どちらの文字色でも約4.5:1のコントラストを保つ。
- 下部に「LCMP を Applications フォルダへドラッグしてください」と、初めて開くときの確認への答え方を表示する。公証したDMGでは「開く」を選ぶこと、ad-hoc署名のDMGではGatekeeperに止められたときの手順（システム設定 › プライバシーとセキュリティ › 「このまま開く」）とし、背景を2枚に描き分ける。
- ボリューム名は「LC Music Player <バージョン>」とする。
- 背景はHiDPIに対応し、1倍と2倍の画像を図形から描く。作り方は[ビルド・配置とローカル配布](../build-and-deploy.md#インストーラーdmgを作る)に記載する。

## 2. メイン画面

### アニメーション領域

メイン画面の上部を、選択中の可視化デザインの置き場所とする。可視化デザインを切り替えても、操作領域の配置や再生状態を変えない。

macOSでは、この領域のドラッグでメインウィンドウを移動する。同じ領域のクリックまたはタップでシークバーを表示する。ドラッグとして扱った操作では、シークバーの表示状態を切り替えない。シークバーやその上の操作部をドラッグした場合も、ウィンドウを移動しない。

### 操作領域

アニメーション領域の下に、次の操作を配置する。

| 左からの順序 | 操作 | 動作 |
| --- | --- | --- |
| 1 | 前の曲 | 再生対象を前の曲へ変更する |
| 2 | 再生・一時停止 | 再生状態に応じて再生、一時停止、再開する |
| 3 | 次の曲 | 再生対象を次の曲へ変更する |
| 4 | 停止 | 再生を停止する |
| 5 | 音量 | アプリ内音量の縦型バーを開く |
| 6 | メニュー | 拡張画面を開閉する |

- 再生・一時停止ボタンを主操作として識別できる外観にする。
- アイコンにはアクセシビリティ上の名前を付け、再生状態に合わせて名前を更新する。
- 利用できない操作は無効状態を明示する。

macOSの操作領域はチャコールを基調とし、背景が透けるグラスのような質感を使用する。主操作を大きな背景色の差で強調せず、記号の発光で状態を表す。透過・ぼかしを用いても操作の視認性を保つ。

再生・一時停止ボタンは三角記号を常設する。三角は再生中に緑のLED風に点灯し、一時停止中は琥珀色、停止中は消灯に近い表示とする。三角の中心を他の操作記号と同じ高さへ揃え、その下に小さなPLAY／PAUSE／STOPの表示を添える。操作のアクセシビリティ名は一時停止・再開・再生に合わせる。

他の主操作ボタンも、押したときに記号がLED風に光って操作への反応を示す。一度の操作への短い発光と、再生中・画面を開いている間の状態表示を区別する。

| 操作 | LED風の反応・状態表示 |
| --- | --- |
| 前の曲・次の曲 | 押したときに短く緑に発光する |
| 停止 | 押したときに短く琥珀色に発光する |
| 音量・メニュー | 押したときに光り、開いている間は緑の点灯を保つ |
| ミュート | 押したときに光り、ミュート中は緑の点灯を保つ |

- 短い発光は操作後に消灯し、ボタンの外で操作を取り消しても残り続けない。
- 状態を示す点灯は、その状態が終わると解除する。
- 無効な操作は発光させない。
- マウス・タッチに加え、キーボード操作でも同じ反応を提供する。

### シークバー

通常はシークバーを表示せず、アニメーション領域をクリックまたはタップすると表示する。再生位置と時間を確認し、バーの操作で再生位置を変更できる。表示中もメイン画面の操作ボタンを使える。

- ポインターや入力フォーカスが外れた後、または他のウィンドウ・アプリへ移った後は約2秒で隠す。
- 操作中は自動非表示を取り消す。Escapeや再クリックでも閉じられる。
- macOSでは細いバーをアニメーション領域の下端へ重ねる。背景は透明または半透明とし、可視化を不透明な帯で隠さない。
- バーの見た目の高さと、操作を受け付ける範囲を区別する。

### 音量

音量ボタンを押すと、縦方向に調整できるバーを表示する。バーはアニメーション領域の高さいっぱいに伸ばし、指やマウスで細かく合わせやすくする。

- 現在値はアプリ内の実音量の割合で表示し、上方向を大きな音量、下方向を小さな音量とする。
- 下半分は小音量を細かく操作できる曲線、50%以上は線形とし、50%の境界で音量と変化の傾きを滑らかにつなぐ。マウス・矢印キー・支援技術の増減で同じ曲線を使う。
- 音量バーを開き直しても実音量は変えない。
- ポップアップ内にミュート操作を置き、解除時にはミュート前のアプリ内音量へ戻す。
- 変更するのはアプリ内の再生音量である。音量の操作でOSのシステム音量を変更しない。出力デバイスごとの音量の記憶・復元は[基本設計](00_basic-design.md)の出力制御に従い、ポップアップの値は出力先が変わると、そのデバイスで最後に使った値になる。

macOSの音量ポップアップは、現在値等を含めた全体をメインウィンドウの高さに収める。閉じる条件は次のとおりとする。

- ポップアップ外の領域をクリックしたとき。クリック先の通常操作も実行する。
- 音量ボタンを再クリックしたとき。
- ポップアップ外へ入力フォーカスが移ったとき、メインウィンドウがキーを失ったとき、他のアプリへ移ったとき。内部のスライダーとミュート間のフォーカス移動では閉じない。
- 開いてから15秒間操作がないとき。音量・ミュート操作のたびに期限を更新する。ドラッグ中は閉じず、解放後から15秒を数える。ホバーだけでは期限を延ばさない。

## 3. 拡張画面

### 配置と開閉

メニューボタンでメイン画面の下に拡張画面を表示する。拡張画面を閉じても再生を続け、選択中の音源・プレイリスト・可視化を維持する。

- macOSではメインウィンドウに付随する拡張ウィンドウとして扱い、メインウィンドウとの位置関係を保つ。2つのウィンドウは、ごく小さい間隔または隙間なしで配置する。
- 下端には控えめなつまみを置き、上下のドラッグで高さを変更できる。幅と上端の位置、メインとの間隔を保ち、画面下端を越えない範囲で拡縮する。高さは同じアプリ実行中の開き直しでも維持する。
- メニューボタンから開いたときの初期表示は、現在の再生リストとする。
- 外観はミニマルな構成を基調とし、メインの操作領域と同等のチャコール・グラスの透過・ぼかしを使用する。
- ファイル選択の取消や選択失敗によって、既存の音源を意図せず差し替えない。

| 機能 | 扱う内容 |
| --- | --- |
| 音楽ファイル選択 | ローカル音源の選択と、現在の音源の確認 |
| プレイリスト編集 | プレイリストと収録曲の管理、再生順序の編集 |
| アニメーション切替 | 可視化デザインの選択 |
| その他設定 | 再生・表示等の設定、最大音量測定と音量自動調整 |

### プレイリスト

- 現在曲の曲名を緑のLED風に光らせ、左端に幅2pt・高さ22ptの控えめなサイドライトを添える。短い曲名でも位置を判別できるようにし、行全体の発光や囲み枠は加えない。
- 一時停止は琥珀色、停止時は発光を抑える。記号と「再生中」「一時停止」「選択中」の文字も併用する。
- リストを開いた直後は現在の再生曲が見える位置へスクロールする。利用者が一覧をスクロールしている間は、その位置を維持する。
- 「現在の再生リスト」の行の右側、曲数の左に少し間を空けてランダム再生の切替を置く。再生モードの切替（将来のリピートを含む）はこの位置に並べ、誤操作を防ぐため互いの間と曲数との間に間隔を取る。文字は使わず、交差する2本の矢印のピクトグラムだけを表示する。ランダム再生中は記号を淡い緑のLED風に光らせ、通常の再生では消灯に近い表示とする。アクセシビリティ名とツールチップは「ランダム再生」、値はオン／オフとする。
- ランダム再生の右に睡眠タイマーの切替を置く。指での誤タップを防ぐため、2つの押せる範囲（各32pt幅）の間を28pt空ける。光る記号どうしの空き（約42pt）と、睡眠タイマーの記号から曲数までの空きをそろえる。記号は月とZ（`moon.zzz`）で、タップ（クリック）でオン・オフを切り替え、長押しで再生する曲数の一覧（1・2・3・5・10曲）を出す。一覧で選んだ曲数は次の起動でも使い、選ぶとタイマーをオンにする。オンの間は記号を淡い緑のLED風に光らせ、右に残りの曲数を小さく出す。途中でオフにしたときは、下がった音量を2.5秒かけて元に戻す。タイマーのオン・オフは保存せず、起動時はオフにする。アクセシビリティ名は「スリープタイマー」、値は「オン、残りN曲」／「オフ、N曲」とし、「曲数を選ぶ」の操作を用意する。
- リスト名と矢印を押すと専用のリスト選択画面へ進む。リスト選択の横には「管理」を置き、プレイリストの新規作成は「管理」画面から行う。曲の追加は「曲を追加」から行う。
- 「管理」からM3U8の読み込みと書き出しを行う。書き出すリストに、書き出し先のフォルダの外にある曲があるときは、書き出す前に「N曲はリストのフォルダの外にあります」と尋ね、「ファイル名だけで書く」（既定）・「フルパスで書く」・「キャンセル」から選ばせる。フルパスにはフォルダの構成（Macではユーザ名）が入ることを説明に添える。外の曲がなければ尋ねない。
- 別のリストを閲覧しても再生対象は維持し、「このリストを再生」または曲行の再生操作で明示的に切り替える。
- 停止・一時停止中は曲行の単クリックで選択し、ダブルクリックでそのエントリから再生する。再生中は別エントリの単クリックで切り替えて再生を続け、現在再生中のエントリの再クリックでは再生位置を戻さない。
- 同じ音源の重複登録も行ごとに区別する。
- 曲行をドラッグすると順序を入れ替えられる。持ち上げた行はポインターに付いて動き、入る位置を緑の線で示す。行の端を越えると一覧が自動でスクロールし、Escで取り消せる。6pt未満の動きはクリックとして扱い、ドラッグした操作では曲を選択・再生しない。右端の上下ボタンもキーボードと支援技術のために残す。
- 「曲を追加」やファイル・フォルダの登録操作は薄い半透明の塗りと小さな角丸に統一し、ボタン下の下線は使用しない。
- 通知欄は通知があるときだけ表示し、空のステータス領域は予約しない。
- スクロールバーは透明なトラックと細い低コントラストのつまみにし、ホイール・トラックパッド・ネイティブの操作範囲を維持する。
- 詳細画面の見出しは「戻る」と画面タイトルの間を14pt空け、操作とタイトルを識別しやすくする。

### 音源一覧と曲の追加

音源一覧、プレイリスト、曲の追加画面は、同じまとめ方と折りたたみを使う。

- 同じアルバムの音源が2曲以上あれば、アルバムのまとまりへ自動で入れる。ファイルと「ミュージック」の曲に同じアルバムがあれば1つにまとめる。アルバムの中はディスク番号・トラック番号の順とし、番号のない曲は番号のある曲の後に登録順で並べる。1曲だけのアルバムの曲やアルバム名のない曲は、次のフォルダの規則に従う。
- アルバムにまとまらなかった音源のうち、フォルダ登録した音源は実際の親フォルダごとに区切る。個別にファイル登録した音源も、同じフォルダの音源がフォルダ登録されているか、同じフォルダから2曲以上を登録すると、そのフォルダのまとまりへ自動で移す。同じフォルダの曲がほかにない個別登録の音源は「デフォルト」にまとめる。
- 各まとまりは初期状態で閉じ、左端の開閉の印（閉じているときは「>」、開くと下向き）・アイコン（アルバムは円盤、フォルダはフォルダ）・名前・曲数を表示する。見出しの行を押すと開閉する。保存場所が異なる同名フォルダは別のまとまりとして扱う。アルバムの名前はアルバム名とし、アーティストの違う同名のアルバムがあるときだけ「アルバム名 — アーティスト」とする。
- まとまりは「デフォルト」「ミュージック」、アルバム（名前順）、フォルダ（パス順）の順に並べる。
- 登録した直後は、タグを読み終えるまで従来のまとまりに表示し、読み終えたものからアルバムへ移る。
- パス文字列は一覧にもツールチップにも表示しない。
- フォルダの所属は保存先から、アルバムの所属はタグから判断し、プレイリストの曲順は変更しない。
- フォルダを閉じても選択した曲は保持し、追加操作は閉じたフォルダ内の選択も含める。
- 音源一覧の登録ボタン（「ファイル」「フォルダ」、iPhoneでは「ミュージック」も）は、アイコンと短い名前で1行に並べ、高さをそろえる。
- 音源一覧では、アルバムとフォルダの見出しの曲数の右にゴミ箱のボタンを置く。確認の後、そのまとまりの全曲をライブラリと各プレイリストから除外する。元ファイルは削除しない。誤操作を防ぐため「デフォルト」には置かない。
- 音源一覧の各曲の行にも、右端の「>」の左にゴミ箱のボタンを置く。曲名を示して確認した後、その1曲をライブラリと各プレイリスト（同じリストに複数回あればすべて）から除外する。元ファイルは削除しない。再生中の曲を除外したときは選択を解除する。
- ゴミ箱のボタンは、見出しと曲の行で同じ縦の位置にそろえる。一覧の右端には、スクロールバーが指やポインタの操作を受ける幅（mac は約15pt、iPhone は12pt）を空け、スクロールしようとしてゴミ箱を押さないようにする。
- 音源一覧の「ライブラリ」の行は、プレイリストの行と同じ配置にする。虫眼鏡（検索）と選択のボタンを、プレイリストの点灯する記号と同じ間隔（誤タップを防ぐ）で並べ、曲数を右端に置く。どちらもランダム再生と同じLEDの記号とし、検索欄を開いている間・選択モードの間は緑に点灯し、それ以外は暗くする。
- 虫眼鏡を押すと検索欄が開く。入力した語で、曲名・ファイル名（拡張子を含む）・フォルダのパス・アルバム名・アーティスト・アルバムアーティストのいずれかに含まれる曲だけを表示し、入力のたびに結果を更新する。「ミュージック」の曲は曲名・種類・タグで探し、ライブラリの内部の参照は対象にしない。大文字と小文字、全角と半角は区別しない。空白で区切った語は、すべてを含む曲だけを残す。
- 検索中は、まとまりを変えずに一致した曲のあるまとまりだけを開いて表示し、手で閉じることもできる。曲数の欄は「一致した曲数 / 全曲数」とする。一致がないときは「一致する曲はありません。」と表示する。×で語を消すと元の表示に戻り、虫眼鏡をもう一度押す（mac は Esc でも）と検索欄を閉じて元の表示に戻る。iPhoneでは、一覧をスクロールするか一覧に触れると、検索欄からフォーカスを外してキーボードを閉じる（キーボードがあると一覧は数行しか見えないため）。入力した語と絞り込みはそのまま残す。
- 選択のボタンで選択モードに入る。曲の行を押すと選択が切り替わり、見出しのチェックで、そのまとまりの表示中の曲をまとめて選ぶ（すべて選ばれていれば外す。一部だけのときは横線で示す）。登録ボタンの行は「すべて選択」（検索中は「一致をすべて選択」）・「選択を解除」・「○曲を除外」に替わる。除外は件数を示して1回だけ確認し、ライブラリと各プレイリストから外して選択モードを終える。選択は検索語を変えても保つ。選択モードの間は、ゴミ箱のボタンを出さない。
- 数千曲のライブラリでも、検索の入力が待たされないようにする。
- 音源一覧の各曲の2行目は、形式（FLAC・M4A等）の右に、その曲が入っているプレイリストの数を「· ≡♪2」の形で示す（同じリストに複数回あっても1つと数える。どのリストにもなければ出さない）。
- 同じ曲が別のファイルでも登録されていれば、2行目に黄色の「· 重複」を添える。同じ曲とみなすのは、アルバム名・アルバムアーティスト（なければアーティスト）・ディスク番号・トラック番号が一致する曲（トラック番号がなければアルバムと曲名が一致する曲）と、アルバムのタグがない場合は親フォルダの名前と曲名が一致する曲である。大文字と小文字、全角と半角は区別しない。「ミュージック」の曲でタグのないものは対象にしない。
- 重複があると、選択モードの間は「すべて選択」の行の下に「重複○曲」と「可逆形式を残す」「非可逆形式を残す」を出す。押すと、同じ曲ごとに1つを残して残りを選ぶ（それまでの選択は置き換える）。残すのは、選んだ種類の形式（可逆：FLAC・ALAC・WAV・AIFF、非可逆：AAC・MP3）の曲、次にプレイリストに多く入っている曲、次に先に登録した曲の順とする。M4Aは中身を読んでALACかAACかを判断し、読めないものはどちらの種類にも当たらないとみなす。検索中は、一致した曲を含む重複だけを対象にする。選んだ後で行を押して選択を変えてもよい。
- 重複から選んだ曲の除外は、件数と「プレイリストに入っている曲は、残す方の曲に付け替える」ことを示して1回だけ確認する。除外する曲のプレイリストのエントリは、同じ曲の残った方（プレイリストに多く入っている方、次に先に登録した方）へ付け替え、曲順を保つ。そのリストに残す方がすでに入っていれば、除外する曲のエントリは外す。元ファイルは削除しない。「すべて選択」「選択を解除」を押すと、通常の除外に戻る。
- 登録の時点ではタグを読んでいないため、登録の時に重複を自動で外すことはしない。

曲の追加画面では次のようにする。

- 表示中のリストにすでに含まれる音源は、曲名を少し落ち着いた文字色にし、「追加済」を添える。色だけに依存せず、支援技術にも追加済みの状態を伝える。
- 追加済みの曲も選択でき、再度追加すると別エントリとして登録する。
- 「ライブラリから選択」の行の右端に、追加済みの曲を隠すトグル（目のアイコン、隠している間は点灯）を置く。既定は表示とし、切り替えた状態はアプリを閉じても保つ。隠すと、追加済みの曲の選択を外す。フォルダのまとまりは隠す前と同じにし、表示する曲がなくなったフォルダは出さない。すべて追加済みのときは「未追加の曲はありません。」と表示する。
- 曲名が表示幅に収まらず省略されている場合だけ、カーソルを重ねると約0.35秒でツールチップに全文を表示する。ツールチップはフォーカスを奪わず、クリック・スクロール・キー入力やウィンドウ変更で消える。
- リストの高さやLED表示を保ち、曲名の自動スクロールは行わない。

### 参照先が見つからない曲

- 通常の曲と同じ行構成にし、右端のマイナスアイコンでプレイリストから外せるようにする。再生できない状態でも削除操作を使え、元の音楽ファイルを削除しない。
- 行を押すと音源側の該当項目へ移動し、ファイルの再選択とライブラリからの除外を行える。この移動では再生対象を変更しない。

### 設定：最大音量測定

- 「最大音量を測定」は既定OFFとし、ONにすると現在曲の曲全体のsample peakを表示する。プレイリストの事前測定はこの表示設定と独立して行う。
- 測定待ち・完了値・測定失敗を表示し、無音は数値の負の無限大ではなく「無音」と示す。
- 測定自体は再生音量を変更しないことを説明する。

### 設定：音量自動調整

- 曲ごとの音量自動調整（「曲ごとの音量をそろえる」）をON/OFFできる。既定はOFFとする。曲全体のLUFSとtrue peakを併用し、手動音量・ミュートとは独立して扱う。
- 目標音量は−23LUFS／−18LUFS／−16LUFSから選ぶ。true-peak上限は−1dBTP、余裕は0.5dB、最大増幅は+6dBとする。
- 測定待ち、適用する補正量、ピーク制約によって目標音量に達しない状態、測定不能や失敗を識別できるようにする。
- 測定は再生前に完了させ、未補正で再生しながら「適用中」と表示しない。
- 曲中の強弱を保つため、ピーク制約で音量がそろわない場合もあることを説明する。
- 再生中に設定を変更しても再生を続け、新しい補正の準備ができたら、その位置から新しい補正で続ける（短い切れ目がある）。一時停止中の変更は、再開のときに準備する。手動音量・ミュートは再生を続けたまま反映し、再測定しない。

状態遷移と画面の接続は[音量自動調整の実装設計](06_volume-normalization-implementation.md)に記載する。

### 設定の表示と背景準備

- 設定の内容は拡張画面の高さに応じて折り返し・スクロールで読めるようにする。
- 音源を背景で準備している間は、拡張画面へ短い状態文だけを示す。測定の進捗バー・スピナー・割合・残り時間は表示しない。
- 曲の選択・切り替えの準備（「音声を準備しています…」「曲全体の音量を測定しています…」）は、準備が0.3秒を超えたときだけ表示する。測定結果がキャッシュにある曲の切り替えは通常0.1秒前後で終わるため、何も表示せずに鳴り始める。
- 準備と保存が成功するまでは旧選択と再生を保つ。停止ボタンは準備中の要求も取り消す。

### ライセンス

設定の「このアプリについて」に、正式名称「LC Music Player (LCMP)」と「バージョン 0.18.42」の形のバージョンを表示し（Info.plistのない開発実行では「開発版」）、「ライセンス…」を開く。アプリメニューの「LCMPについて」は、macOS標準の情報パネルで同じ名称とバージョンを表示する。ビルド番号はバージョンの末尾に含まれるので、括弧書きで重ねて表示しない。

- 独立した不透明なタイトルバーに「LCMP — ライセンス」を表示する。依存がない現在は1枚の表示で、見出し「LC Music Playerのライセンス」の下に文書選択（LICENSE・NOTICE）と原文表示を置く。依存を加えた場合は、対象の一覧（先頭にLCMP本体、続けて依存）を左に置き、謝辞の説明文を添える。
- 外観はメインと同じチャコール・グラス、控えめな緑、明るい本文色で統一する。白い一覧・本文背景は置かず、本文の選択範囲も低彩度の緑にする。
- 原文は文字を選択してコピーでき、長文をスクロールできる。
- 再度開く操作は同じウィンドウを前面へ出し、閉じた後も再表示できる。
- 最小の拡張画面では設定内をスクロールしてボタンへ到達する。
- 開閉だけで再生や音量・ライブラリを変更しない。外部URLは明示操作で開き、同梱資源が読めない場合は理由を表示する。

## 4. 状態の伝え方

- 再生中・一時停止・停止は主操作のアイコンと操作可能なボタンで識別する。
- 音源が未選択の場合は、メニューから音源を選ぶ導線を示す。
- エラーは原因と回復操作をメイン画面でも識別できるようにする。楽曲名を大きく表示する方法で伝えない。
- 可視化表示の停止と再生制御を分離し、画面の開閉や可視化の切替で音源や音量を変更しない。
- ポインター操作に加え、キーボードと支援技術から表示切替・シーク・音量・メニューを操作できるようにする。

## 5. 可視化デザインの構成

アニメーション領域は可視化デザインを差し替えるためのコンテナとする。再生制御、解析データ、描画を別の責務として扱う。

現在のPlayer UIの名称は`LCMP_default_GEQ`である。可視化デザインは次の3つで、拡張画面の表示タブで切り替える。切り替えても操作領域・再生・音量は変わらず、選んだデザインは次の起動でも使う。

| 表示名 | 説明（カードの2行目） | 内容 |
| --- | --- | --- |
| Last Century イコライザー | 1990年代の懐かしさをお届け | 16列の蛍光管LED |
| MICRIGAIKE コジョーズ | 山上の素敵な秘湯では、毎晩オコジョ達がステージを開くらしい... | 5匹のオコジョの合唱 |
| 教育番組 | 思ってたのと違うけど、これはこれで味がある。絵心が欲しい... | 4体のパペットの歌と、移り変わる風景 |

表示タブには、デザインごとにサムネイル・表示名・説明（2行まで）を並べたカードを置く。選んでいるカードは緑の枠と緑の文字で示す。

### Last Century イコライザー（蛍光管LED）

- 蛍光管LED風の表示を基調とし、16列の間に余白を設ける。
- 縦軸の表示範囲は−80〜0dBFSとする。
- セルの色は下半分を蛍光緑、次の4分の1を蛍光黄、上の4分の1を蛍光赤とする。
- セル本体は1つずつ全体をONまたはOFFに切り替える。セルの一部だけが点灯する表示や、入力レベルに応じてセル内の明るさが連続的に変化する表示は行わない。
- 点灯したセルの周囲には淡い光のにじみを添え、消灯時には短い残光を残して消す。
- セルのない部分は暗い背景とし、消灯中のセルも緑・黄・赤に対応する暗い色で識別できるようにする。

実解析との接続・提示時刻・描画方法は[可視化の実装設計](08_visualization-implementation.md)に記載する。

### MICRIGAIKE コジョーズ（オコジョ合唱団）

- 暗い舞台の木箱の上に、デフォルメした5匹のオコジョが寄り添って並び、左の低音から右の高音までの音域を1匹ずつ受け持って歌う。曲ごとに音域の感度を合わせ、どの曲でも全員が歌う。
- 舞台は、オコジョたちが手作りしたように見せる。木の梁にピンクのネオン管の看板「MICRIGAIKE KOJOES」を少し傾けて吊るし、梁から吊るした照明が歌に合わせて上から、床置きの照明が低音に合わせて下から照らす。看板は、高音の強い音でときどき1〜2文字だけ短く明滅する。音楽に関係なく点滅し続ける飾りにはしない。照明の光の筋の中には、ライブハウスのように小さなホコリが漂ってきらめく。
- 全員が拍にそろって弾み、同じ向きに揺れて、同じ曲を歌っている一体感を出す。腕はフレーズごとに、祈る・差し伸べる・両手を広げる・片腕を上げる・観客を指さすといった意味のあるポーズを保ち、ばたばた動かさない。
- 互いを見たり、目立つ音域の子に注目したり、サビでウェーブしたり、曲の終わりにお辞儀したりと、キャラクタ同士の連動で見せる。
- 画調は日本の手描きアニメ・漫画とし、インクの線と2色のセル影で描く。描いた原画を順に見せ、原画のあいだを中割りで埋めて30fpsで動かす。
- 5匹は性格が違い、動きと表情でそれを見せる。左右の揺れは控えめにし、上下の弾みと表情の変化で歌を表す。
- 動きを減らす設定では、体を動かさず、表情と口だけで歌う。照明の明るさも変えない。

各キャラクタの性格と実装は[オコジョ合唱団の実装設計](12_ermine-chorus-implementation.md)に記載する。

### 教育番組（パペット）

- ペーパークラフト調の風景の前に、布でできた4体のパペットが並び、左から高音・低音・中低音・中高音を1体ずつ受け持って歌う。口は全員が拍に合わせて開き、開く量は受け持つ音域の強さで変わる。
- パペットは頭が球に近い3Dの人形で、肌の色の布に眼鏡と目だけを貼り、口は頭の水平の切れ込みとする。体は拍で沈み、2拍ごとに左右へ小さく揺れ、腕と向きはフレーズごとに変える。
- 盛り上がりで目が光り（4体それぞれの色と光り方）、いちばん強い盛り上がりではシャウトする。ツンツン髪はヘッドバンギングし、鳴り止むと全員がぐったりする。互いを見たり、目が合って照れたり、2人がそろって同じ振り付けをしたりと、掛け合いで見せる。
- 背景は空・太陽と月・星・雲・鳥や飛行機・風景の層でできており、再生中だけ6分で1日の速さで朝・昼・夕・夜と移り変わり、風景が1日で1周横へ流れる。月は実際の月齢で欠ける。時刻の光の色はパペットにも掛かる。
- 動きを減らす設定では、体を動かさず、口と表情と目だけで歌う。流れ星と彗星は出さない。

構成と実装は[教育番組（パペット）の実装設計](14_puppet-show-implementation.md)に記載する。

### 共通

可視化の実装は専用のフォルダにまとめる。独自の世界観を持つデザイン（MICRIGAIKE コジョーズ、教育番組）は、デザインごとのフォルダ（`Players/Micrigaike_Kojoes/`、`Players/Kyouiku_Bangumi/`）に構成するファイル一式を置く。共通の解析データを各デザインへ渡し、デザインの変更がファイルアクセス、音源デコード、音量制御へ影響しない構造にする。

## 6. iPhone版の画面

iPhone版は、macOS版と同じメイン画面・拡張画面・可視化を、iPhoneの画面の向きに合わせて並べる。操作の順序・LEDの反応・拡張画面の内容はmacOS版と共通にする。実装は[iPhone版の実装設計](13_iphone-implementation.md)に記載する。

### 縦置き

- 通常の起動では、上にメイン画面、下に拡張画面を並べる。メイン画面はmacOS版と同じ縦横比（360:210）で、画面の幅に合わせて拡大する。拡張画面は画面の下端まで伸ばし、高さを変えるつまみは置かない。
- メニューで拡張画面を閉じると、メイン画面を画面の中央に置く。
- 拡張画面の文字は、macOS版より大きくして読みやすくする。

### 横置き

- 拡張画面を閉じているときは、プレイヤーを全画面にする。可視化の黒い地と操作部のグラスの帯は画面の端まで伸ばし、角の丸いカードが途中で切れたように見せない。LEDとボタンはDynamic Islandとホームバーを避けた範囲に置き、上に約10ptの余白を取る。周波数の文字は16ptにする。
- 拡張画面を開いているときは、左にメイン画面、右に拡張画面（幅360pt）を並べる。
- LEDは画面の解像度で描き直し、拡大しても荒くしない。列数は縦置きと同じ16列とする。
- 横置きの操作ボタンは縦置きより大きくする（全画面で記号24pt・押せる範囲56pt、拡張と並べるときは21pt・52pt）。
- 回転しても、再生と拡張画面の開閉の状態を変えない。

### タッチの操作

- アニメーション領域のタップでシークバーを表示する。シークバーと音量バーは指で操作しやすい高さにする。
- 音量バーの外をタップすると音量バーを閉じる。
- プレイリストの曲は、停止・一時停止中はダブルタップで再生し、再生中は別の曲のタップで切り替える。長押しで行を持ち上げ、そのままドラッグして順序を入れ替える。長押しが成立する前に指が動いたときは、行の上から始めても一覧をスクロールする。
- ファイル・フォルダの登録とプレイリストの読み込みはiOS標準の書類の選択画面で行い、iCloud Drive・このiPhone内・OneDriveなど、ファイルアプリに出る場所から選べる。提供元がフォルダの選択を許さない場所（OneDrive等）では、ファイルを選んで登録する。プレイリストの書き出しは、書き出したファイルを選んだ場所へ移す。ファイルの曲を含むリストでは、書き出す前にmacOSと同じ確認をアラートで出す。
- 音源タブの「ミュージック」と曲の追加画面の「ミュージックから…」で、iOS標準の曲の選択画面を開き、「ミュージック」のライブラリの曲を複数選んで登録できる。選べるのは端末にあるDRMのない曲（Macから同期した曲・購入した曲等）で、Apple Musicのサブスクリプションの曲とiCloudにだけある曲は出さない。初回はライブラリへのアクセスの許可を求め、許可がないときは設定を開く案内を出す。
- ライブラリの曲は、音源一覧で「ミュージック」のまとまりに入れ、曲名をライブラリの曲名で表示する。ライブラリから消えた曲は参照切れとして扱う。
- 設定の「このアプリについて」の「ライセンス…」は、シートでライセンスを表示する。

### 常時表示

- 表示タブの上部の右端に、常時表示の切替を置く。記号は太陽（`sun.max`）とし、文字は使わない。
- タップでオン・オフを切り替える。オンの間は自動ロックをせず、記号を淡い緑のLED風に光らせる。オフでは消灯に近い表示とする。
- 充電していない状態で電池残量が30%以下になったら、オンのまま自動ロックを戻し、記号を琥珀色にする。充電を始めるか電池残量が30%を超えると、ふたたび自動ロックをしない。
- 状態は保存せず、起動時はオフにする。アクセシビリティ名とツールチップは「常時表示」、値はオン／オフ／電池残量が少ないため解除中とする。
- macOS版には置かない。

### ロック画面・Dynamic Island・ウィジェット

iOSの制約で、ロック画面・Dynamic Island・ウィジェットは連続したアニメーションを描けない。ここには操作部だけを置き、可視化はアプリの画面で見る。

- ロック画面・コントロールセンター・Dynamic Islandは、iOSのシステムの「再生中」に任せ、LCMP独自の表示（ライブアクティビティ）は出さない。独自の表示を足すと、ロック画面で「再生中」と二重に並ぶためである（Dynamic Islandだけに出してロック画面には出さない、という指定はiOSにない）。
- 「再生中」には、曲名・アートワークを出さず、アプリ名「LC Music Player」とアプリのアイコンだけを表示し、経過時間のバーも出さない。ヘッドホンのボタン・コントロールセンター・ロック画面・Dynamic Islandの長押しから、再生・一時停止・前後の曲・停止を操作できる。曲の中の早送り・巻き戻し（再生位置の変更）は出さない。
- ホーム画面のウィジェットは、チャコールの板とLEDの記号にする。小は上段に再生・一時停止とメニュー、下段に前の曲と次の曲を置く。中は上段にメーターの印・アプリ名・メニュー、下段に前の曲・再生・一時停止・次の曲・停止を置く。大きさはiOSの決めた枠に従う。曲名は出さない。
- メニュー（☰）はアプリを開いて拡張画面を表示する。
- 再生中は再生の三角を緑に、一時停止中は琥珀色に光らせ、停止中は消す（メイン画面と同じ）。アプリとウィジェットで状態を共有できない署名の環境では、再生・一時停止を1つの切り替えの記号にして光らせない。
- ウィジェットのボタンは、アプリが前面にないときも終了しているときも、メイン画面の同じボタンと同じ操作をする。

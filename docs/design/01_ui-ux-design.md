# LCMP UI・UX設計

[設計書一覧](../README.md)に戻る。

本書はLCMPで目指す画面構成と操作を記述します。単曲再生の実装構造は[基本再生の実装設計](02_playback-implementation.md)で管理します。

macOS版の外観と配置は、[チャコール・グラスと三角LEDの画面見本](../../prototypes/led-player.html)を基準にします。画面見本の可視化は表示例であり、再生音に応じた描画は可視化機能が担当します。

## 1. 画面の方針

可視化と日常の再生操作をまとめたコンパクトなメイン画面を使用します。通常はメイン画面のみを表示し、音源管理や設定が必要なときに拡張画面を開きます。

- メイン画面にタイトルバーを表示しない。
- macOSのメインウィンドウと拡張ウィンドウは、適度に丸めた角丸を使用し、macOSの他のGUIより少しシャープな印象にする。
- 可視化を主役とし、楽曲名やアートワークを常設しない。楽曲情報は拡張画面で確認する。
- メイン画面の操作順序と構成はmacOSとiPhoneで共用できるようにする。
- メイン画面はiPhoneの画面幅に収まるサイズ感とし、ボタンの操作領域を確保する。
- ウィンドウの移動や画面の提示方法は、各OSの画面管理に合わせる。

## 2. メイン画面

### アニメーション領域

メイン画面の上部を、選択中の可視化デザインの置き場所とします。可視化デザインを切り替えても、操作領域の配置や再生状態を変えません。

macOSでは、この領域のドラッグでメインウィンドウを移動します。同じ領域のクリックまたはタップでシークバーを表示します。ドラッグとして扱った操作では、シークバーの表示状態を切り替えません。シークバーやその上の操作部をドラッグした場合も、ウィンドウを移動しません。


### 操作領域

アニメーション領域の下に、次の操作を配置します。

| 左からの順序 | 操作 | 動作 |
| --- | --- | --- |
| 1 | 前の曲 | 再生対象を前の曲へ変更する |
| 2 | 再生・一時停止 | 再生状態に応じて再生、一時停止、再開する |
| 3 | 次の曲 | 再生対象を次の曲へ変更する |
| 4 | 停止 | 再生を停止する |
| 5 | 音量 | アプリ内音量の縦型バーを開く |
| 6 | メニュー | 拡張画面を開閉する |

再生・一時停止ボタンを主操作として識別できる外観にします。アイコンにはアクセシビリティ上の名前を付け、再生状態に合わせて名前を更新します。利用できない操作は無効状態を明示します。

macOSの操作領域はチャコールを基調とし、背景が透けるグラスのような質感を使用します。主操作を大きな背景色の差で強調せず、記号の発光で状態を表します。透過・ぼかしを用いても操作の視認性を保ちます。

再生・一時停止ボタンは三角記号を常設し、再生中は緑のLED風に点灯、一時停止中は琥珀色、停止中は消灯に近い表示とします。三角の中心を他の操作記号と同じ高さへ揃え、その下に小さなPLAY／PAUSE／STOPの表示を添え、操作のアクセシビリティ名は一時停止・再開・再生に合わせます。

他の主操作ボタンも押したときに記号がLED風に光り、操作への反応を示します。一度の操作への短い発光と、再生中・画面を開いている間の状態表示を区別します。無効な操作は発光させません。マウス・タッチに加え、キーボード操作でも同じ反応を提供します。

| 操作 | LED風の反応・状態表示 |
| --- | --- |
| 前の曲・次の曲 | 押したときに短く緑に発光する |
| 停止 | 押したときに短く琥珀色に発光する |
| 音量・メニュー | 押したときに光り、開いている間は緑の点灯を保つ |
| ミュート | 押したときに光り、ミュート中は緑の点灯を保つ |

短い発光は操作後に消灯し、ボタンの外で操作を取り消しても残り続けません。状態を示す点灯は、その状態が終わると解除します。常時の点滅や明滅は使用しません。

### シークバー

通常はシークバーを表示せず、アニメーション領域をクリックまたはタップすると表示します。再生位置と時間を確認し、バーの操作で再生位置を変更できるようにします。表示時もメイン画面の操作ボタンを使えます。ポインターや入力フォーカスが外れた後、または他のウィンドウ・アプリへ移った後は約2秒で隠します。操作中は自動非表示を取り消し、Escapeや再クリックでも閉じられます。

macOSでは細いバーをアニメーション領域の下端へ重ねます。背景は透明または半透明とし、可視化を不透明な帯で隠しません。バーの見た目の高さと、操作を受け付ける範囲を区別します。

### 音量

音量ボタンを押すと、縦方向に調整できるバーを表示します。現在値はアプリ内の実音量の割合で表示し、上方向を大きな音量、下方向を小さな音量として扱います。下半分は小音量を細かく操作できる曲線、50%以上は線形とし、50%の境界で音量と変化の傾きを滑らかにつなぎます。音量バーを開き直しても実音量は変えません。マウス・矢印キー・支援技術の増減で同じ曲線を使います。

macOSの音量ポップアップは、現在値等を含めた全体をメインウィンドウの高さに収めます。ポップアップ外の領域をクリックすると閉じ、クリック先の通常操作も実行します。音量ボタンの再クリックでも閉じます。ポップアップ外へ入力フォーカスが移ったとき、メインウィンドウがキーを失ったとき、他のアプリへ移ったときも閉じます。内部のスライダーとミュート間のフォーカス移動では閉じません。開いてから15秒間操作がない場合も閉じ、音量・ミュート操作のたびに期限を更新します。ドラッグ中は閉じず、解放後から15秒を数えます。ホバーだけでは期限を延ばしません。

ポップアップ内にミュート操作を置き、解除時にはミュート前のアプリ内音量へ戻します。

変更するのはアプリ内の再生音量です。OSのシステム音量を直接変更しません。出力デバイスごとの音量記憶・復元は[基本設計](00_basic-design.md)の出力制御に従います。

## 3. 拡張画面

メニューボタンでメイン画面の下に拡張画面を表示します。拡張画面を閉じても再生を継続し、選択中の音源・プレイリスト・可視化を維持します。

macOSではメインウィンドウに付随する拡張ウィンドウとして扱い、メインウィンドウとの位置関係を保ちます。2つのウィンドウは、ごく小さい間隔または隙間なしで配置します。

拡張画面の下端には控えめなつまみを置き、上下のドラッグで高さを変更できるようにします。幅と上端の位置、メインとの間隔を保ち、画面下端を越えない範囲で拡縮します。高さは同じアプリ実行中の開き直しでも維持します。

メニューボタンから拡張画面を開くときの初期表示は、現在の再生リストとします。

リストを開いた直後は現在の再生曲が見える位置へスクロールし、再生対象の行を視覚的に識別できるようにします。利用者が一覧をスクロールしている間は、その位置を維持します。

macOSの拡張画面はミニマルな構成を基調とし、メインの操作領域と同等のチャコール・グラスの透過・ぼかしを使用します。

拡張画面の外観は[文字LED＋細いサイドライトの画面見本](../../prototypes/minimal-glass-combined.html)の先頭案を基準とします。現在曲の曲名を緑のLED風に光らせ、左端に幅2pt・高さ22ptの控えめなサイドライトを添えます。短い曲名でも位置を判別できるようにし、行全体の発光や囲み枠は加えません。一時停止は琥珀色、停止時は発光を抑え、記号と「再生中」「一時停止」「選択中」の文字も併用します。

リスト名と矢印を押すと専用のリスト選択画面へ進みます。別のリストを閲覧しても再生対象は維持し、「このリストを再生」または曲行の再生操作で明示的に切り替えます。停止・一時停止中は曲行の単クリックで選択し、ダブルクリックでそのエントリから再生します。再生中は別エントリの単クリックで切り替えて再生を続け、現在再生中のエントリの再クリックでは再生位置を戻しません。同じ音源の重複登録も行ごとに区別します。「曲を追加」やファイル・フォルダの登録操作は薄い半透明の塗りと小さな角丸に統一し、ボタン下の下線は使用しません。通知欄は通知があるときだけ表示し、空のステータス領域は予約しません。

スクロールバーは透明なトラックと細い低コントラストのつまみにし、ホイール・トラックパッド・ネイティブの操作範囲を維持します。常時点滅する装飾は使用しません。

プレイリストの新規作成は「管理」画面から行います。リスト選択の横には「管理」を置き、曲の追加は「曲を追加」から行う構成にします。

プレイリスト、音源一覧、曲の追加画面も音源一覧と同じフォルダ分け・名前・曲数・初期状態が閉じた折りたたみを使用する。個別登録は「デフォルト」にまとめ、パスは表示しない。フォルダを閉じても選択した曲は保持し、追加操作は閉じたフォルダ内の選択も含める。

曲の追加画面では、曲名が表示幅に収まらず省略されている場合だけ、カーソルを重ねると約0.35秒でツールチップに全文を表示します。全文が収まる場合は表示しません。ツールチップはフォーカスを奪わず、クリック・スクロール・キー入力やウィンドウ変更で消えます。リストの高さやLED表示を保ち、曲名の自動スクロールは行いません。

詳細画面の見出しは「戻る」と画面タイトルの間を14pt空け、操作とタイトルを識別しやすくします。

音源一覧はフォルダ登録した音源を実際の親フォルダごとに区切り、個別にファイル登録した音源は「デフォルト」にまとめます。各まとまりは初期状態で閉じ、フォルダアイコン・名前・曲数を表示します。パス文字列は一覧にもツールチップにも表示しません。各フォルダは折りたため、保存場所が異なる同名フォルダは別のまとまりとして扱います。フォルダの所属は保存先から判断し、プレイリストの曲順は変更しません。

曲の追加画面では、表示中のリストにすでに含まれる音源の曲名を少し落ち着いた文字色にし、「追加済」を添えます。色だけに依存せず、支援技術にも追加済みの状態を伝えます。追加済みの曲も選択でき、再度追加すると別エントリとして登録します。

参照先が見つからない曲も通常の曲と同じ行構成にし、右端のマイナスアイコンでプレイリストから外せるようにします。再生できない状態でも削除操作を使えるようにし、元の音楽ファイルを削除しません。

参照先が見つからない曲の行を押すと、音源側の該当項目へ移動します。音源側でファイルの再選択とライブラリからの除外を行えるようにします。ファイル参照の確認画面への移動では再生対象を変更しません。

| 機能 | 扱う内容 |
| --- | --- |
| 音楽ファイル選択 | ローカル音源の選択と、現在の音源の確認 |
| プレイリスト編集 | プレイリストと収録曲の管理、再生順序の編集 |
| アニメーション切替 | 可視化デザインの選択 |
| その他設定 | 再生・表示等の設定、最大音量測定のON/OFFと状態・結果 |

拡張画面は可視化領域から独立した操作領域です。ファイル選択取消や選択失敗によって、既存の音源を意図せず差し替えません。

## 4. 状態の伝え方

- 再生中・一時停止・停止は主操作のアイコンと操作可能なボタンで識別する。
- 音源が未選択の場合は、メニューから音源を選ぶ導線を示す。
- エラーは原因と回復操作をメイン画面でも識別できるようにする。楽曲名を大きく表示する方法で伝えない。
- 可視化表示の停止と再生制御を分離し、画面の開閉や可視化の切替で音源や音量を変更しない。
- ポインター操作に加え、キーボードと支援技術から表示切替・シーク・音量・メニューを操作できるようにする。

## 5. 可視化デザインの構成

アニメーション領域は可視化デザインを差し替えるためのコンテナとします。再生制御、解析データ、描画を別の責務として扱います。

現在のPlayer UIと可視化の名称は`LCMP_default_GEQ`です。グラフィックイコライザーは蛍光管LED風の表示を基調とし、16列の間に余白を設けます。縦軸の表示範囲は−80〜0dBFSです。セルの色は下半分を蛍光緑、次の4分の1を蛍光黄、上の4分の1を蛍光赤とします。セル本体は1つずつ全体をONまたはOFFに切り替え、セルの一部だけが点灯する表示や、入力レベルに応じてセル内の明るさが連続的に変化する表示は行いません。

点灯したセルの周囲には淡い光のにじみを添え、消灯時には短い残光を残して消します。セルのない部分は暗い背景とし、消灯中のセルも緑・黄・赤に対応する暗い色で識別できるようにします。

外観の見本は[16列の蛍光管LED](../../prototypes/fluorescent-led.html)、実解析との接続・提示時刻・描画方法は[可視化の実装設計](08_visualization-implementation.md)を参照します。

可視化の実装は専用のフォルダにまとめ、各デザインをその配下のサブフォルダへ分けます。共通の解析データを各デザインへ渡し、デザインの変更がファイルアクセス、音源デコード、音量制御へ影響しない構造にします。

## 最大音量測定と再生準備

設定の「最大音量を測定」は既定OFFとし、ONにすると曲全体のsample peakを表示する。プレイリストの事前測定はこの表示設定と独立して行う。測定待ち・完了値・測定失敗を表示し、無音は数値の負の無限大ではなく「無音」と示す。測定自体は再生音量を変更しないことを説明する。設定内容は拡張画面の高さに応じて折り返し・スクロールで読めるようにする。

音源を背景で準備している間は拡張画面へ短い状態文だけを示す。測定の進捗バー・スピナー・割合・残り時間を表示しない。高機能を簡素に見せ、少し古く懐かしい操作感を保つ。準備と保存が成功するまでは旧選択と再生を保ち、停止ボタンは準備中の要求も取り消す。

## 音量自動調整

拡張画面の設定から、曲ごとの音量自動調整をON/OFFできるようにする。曲全体のLUFSとtrue peakを併用し、手動音量・ミュートとは独立して扱う。測定だけの設定と、実際に音を補正する設定を区別する。

自動調整の測定待ち、適用する補正量、ピーク制約によって目標音量に達しない状態、測定不能や失敗を識別できるようにする。測定は再生前に完了させ、未補正で再生しながら「適用中」と表示しない。曲中の強弱を保つため、ピーク制約で音量がそろわない場合もあることを説明する。具体的な状態遷移、移行と画面の接続は[音量自動調整と前処理拡張の設計](06_audio-processing-design.md)を参照する。

音量自動調整は既定OFFとし、目標音量は基準−23LUFS／−18LUFS／−16LUFSから選ぶ。基準のtrue-peak上限は−1dBTP、余裕は0.5dB、最大増幅は+6dBとする。自動調整の設定変更時は一時停止して位置を保持し、利用者の再生操作で準備後に再開する。手動音量・ミュートは再生を継続して反映し、再測定しない。

## 謝辞の表示

設定の「このアプリについて」から「謝辞とライセンス…」を開きます。独立した不透明なタイトルバーに「LCMP — 謝辞とライセンス」を表示し、ウィンドウ内に依存一覧と文書選択・原文表示を設けます。外観はメインと同じチャコール・グラス、控えめな緑、明るい本文色で統一します。白い一覧・本文背景は置かず、本文の選択範囲も低彩度の緑にします。原文は文字を選択してコピーでき、長文をスクロールできます。再度開く操作は同じウィンドウを前面へ出し、閉じた後も再表示できます。最小の拡張画面では設定内をスクロールしてボタンへ到達します。開閉だけで再生や音量・ライブラリを変更しません。外部URLは明示操作で開き、同梱資源が読めない場合は理由を表示します。
